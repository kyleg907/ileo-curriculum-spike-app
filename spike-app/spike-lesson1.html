Lesson 1: Write a Simple Drive Forward Program

To make the robot move, we need to tell the brick what motor ports we connected the drive motors (the motors attached to the wheels) to. Then we can command the motors to move and drive the robot. We’ll build the program with the SPIKE App on a laptop or tablet, then we’ll connect to the robot and download your program to test it.

Create a Project

Click the gray ‘plus’ icon near the middle of the screen to create a new project.

SPIKE App offers three options for creating programs:

  • WORD BLOCKS
    • Similar to SCRATCH. https://scratch.mit.edu
    • We recommend word blocks for all programs.
    • This document will only cover word blocks.
  • ICON BLOCKS: (similar to EV3 Lab for those who have used that in the past)
  • Python - A popular programming language used by professionals and hobbyists. Ask your mentors if they use Python! https://python.org

Click the Home icon in the navigation bar, and click New Project. Then name the project with something descriptive like My first SPIKE Project, click WORD BLOCKS, then click the Create button.

Tip

Choose WORD BLOCKS when creating your programs.

Tip

Always use descriptive names for your projects. It will make them easier to find on your device. SPIKE bricks do not have an LCD display like other MINDSTORMS robots do, so you cannot see which programs the brick contains. The SPIKE App loads programs into slots numbered 0 through 19.

The white open area is the Programming Canvas. This is where you will add programming blocks to control your robot. The colorful side part is the Block Palette where the programming blocks live. You can click on the colored dots to scroll the Block Palette to a specific set of functions.

Writing the Code

The SPIKE App can download and run programs in a single step with the Play button. With the Play button, the robot could start moving when you’re not quite ready: the USB cable might be connected, you may wish to put the robot on the ground, etc. So we’ll start every program with a wait block that will prevent the rest of the program from running until you press a brick button.

Programming Exercise

Click and drag an orange control wait until block from the Block palette. Drag it near the when program starts block on the canvas, then a shadow will appear, and then you can release the block and the new block will snap into place. This is how you’ll build your entire program.

Now click and drag a teal sensors is left button pressed block and drop it to the wait until block to place this sensor command into the wait until block.

Click and drag the pink movement block set movement motors to block from the Block palette. Each programming block tells the robot different things to do. The set movement motors to block configures two motors that other movement blocks control.

By convention (meaning a common practice), we connect SPIKE motor ports A and B (the first ports on either side of the intelligent brick) to the drive motors. If you follow this convention, it will save you a little time in creating your programs. You may select any of the ports A through F to use as drive motors, or for any other function, you’ll just have to remember to change the blocks to use the correct port when you add them to the program. Sensors, as we’ll discuss later, can also plug into any of the A-F ports. Interestingly, the Driving Base 1 robot we typically build with this lesson does not follow this convention. So today you’ll need to change the ports in the program, or move the wires on your robot.

Next, click and drag a pink movement move block from the Block Palette and connect it to your program. Click the Your program should look like the following figure. Avoid the start moving blocks for any of your programs for now.

With the Driving Base 1 robot, and the pink movement blocks, moving forward means moving the motors clockwise. With other robot designs or motor orientations, you might need to adjust your program as you may need to tell the program to move backward so certain robots move forward. That or you have a mistake (or bug) in your program or robot design.

But if we mount the motor upside down on the robot and the program tells the motor to move FORWARD, the robot will actually move BACKWARD. This isn’t wrong, we might have to adjust the program to make the robot behave how we want. Also, depending on what motor you connect as B or C, left and right could be the opposite of what you expect, which you must adjust for to make the robot steer the way you want.

Power on your robot. On the Spike brick, press the large round button until it lights up.

Note

These are common errors when building and programming an SPIKE robot. Check these first when you have problems:

  • The ports specified in the program do not match robot build. Depending on how far along you are, it might be easier to change the program or the robot.
  • Make sure C and D are selected as shown by clicking C first for left and D second for right. If you click them in the wrong order, or accidentally C or D a second time, the order will be reversed. This means that when your program says “go forward” the robot will move backward, and turning left and right will be reversed.
    • With Driving Base 1 the back of the robot (and backward direction) is where the white roller ball and the bottom of the brick where the left, right and large button are.
  • Forgetting to connect a wire from the intelligent brick to the motor or wire.
  • The wire might not be fully seated in the port. Unplug and re-plug the wires on the brick side.

Download the Program to the SPIKE brick

Connect your device to the SPIKE brick using one of these methods.

  • Connect the robot using the USB cable from your SPIKE kit. This is faster and less troublesome. This is supported with the following devices:
    • SPIKE App with a Windows or Mac computer.
    • The SPIKE web app with Google Chrome web browser on Windows, Mac, or Chromebook.
  • If you are using a tablet or a Chromebook with the SPIKE App, you’ll connect with Bluetooth.

Right now, the Connect icon on the Programming Canvas should show a red dot, indicating no SPIKE is connected. Follow the instructions below for the connection method you choose.

Option 1: Connecting with a USB cable

This is the fastest and easiest method, but only works with Windows or Mac versions of SPIKE App, or with the web-based version of the SPIKE App with the Google Chrome browser.

Connect the small end of the USB cable to the USB port on top of the SPIKE brick (one the side with the small Bluetooth button). The first time connecting a robot it may take some time to install drivers before the connection process will complete. The Connect icon show now show a green dot.

You might check that Bluetooth and Wifi are turned off on the brick, as you do not need them. This will save battery power.

Option 2: Connecting with Bluetooth

Note

If you are using the SPIKE web app with the Chrome browser, it does not support connecting to SPIKE over Bluetooth. You must use the USB cable as described in the previous section.

Most devices that run SPIKE App have Bluetooth, a wireless technology that lets devices communicate. You’ve probably seen or used it to connect phones, tablets, speakers, headphones, entertainment or other devices together. Bluetooth must be enabled on the device and on the SPIKE brick, and the devices paired together. Sometimes Bluetooth connection can be problematic to setup or reconnect. Ask an instructor if you are having trouble with this.

  1. Check that Bluetooth is enabled on the device that is running SPIKE App. Typically, you can access this in the taskbar or settings. It might take a few moments for Bluetooth to start.

  2. Enable Bluetooth on the SPIKE brick. Press the smaller button near the top of the brick that is marked with the Bluetooth ‘B’ symbol. SPIKE App also will show these steps when you try to connect. If this is the first time pairing this brick with your device, the Bluetooth button will flash and beep.

  3. Click the connect icon on your Programming Canvas in SPIKE App and follow the instructions to connect your SPIKE.

    • A platform-specific dialog will appear showing SPIKE bricks (though you might need to wait a moment for SPIKE App to find and display your SPIKE). In a classroom environment there might be several. Hopefully, the name of the brick is the same as your MINDSTORMS kit number. Select the name of your brick.

    • The brick should connect.

  4. Click the BACK TO PROJECT button. The connect icon should change.

  5. When connected, SPIKEshows the status of the connected motors and sensors. Clicking the connect icon will show more details about the connected sensors and motors. This is very useful when debugging your programs and understanding sensor inputs later.

    Note

    You can rename the brick on this screen, but please avoid using a name other than your kit ID. This will help your instructors deal with connection problems in the class, and to ensure the bricks are placed with their correct kits.

If you have trouble with the Bluetooth connection work with your instructors and try these steps:

  • Close the SPIKE App.
  • Go into the settings for your device, find the Bluetooth settings. Un-pair any LEGO robots your device has previously connected to. The will vary depending on your platform (e.g. Forget this device action on iPad) .
  • Turn off Bluetooth on your device, wait a few moments then turn it back on.
  • You might even restart the device that is running SPIKE App.
  • Turn your SPIKE brick off, then back on.
  • Attempt to pair the brick again.

Prepare to Run (and Emergency Stop) the Program

Prepare the work area (and yourself) to make sure the robot, cables and computer won’t be damaged or become tangled when the robot starts moving. Be careful so the robot does not drive off of a table: running the robot on the floor might be better.

Try not to disrupt others around you. You may need to quickly grab or stop the robot if it MISBEHAVES!

To stop the robot while your program runs, press the large white button: - Practice finding and pressing the button now.

To download the program to the SPIKE brick, click the yellow play button at the bottom of the programming canvas. This will download and run the program in a single step. Because we added the wait until block, the program will be running, but the robot will not perform any action until we press the left button on the brick.

The program should download and run, but it will wait for you to press the left brick button. Prepare your area, remove the USB cable if it is connected, and place the robot (e.g. on the floor) to prepare it to run. Be ready to grab the robot and stop the program if it malfunctions. Press the left button on the brick now to run the remainder of your program.

If your robot moves forward slightly, CONGRATULATIONS! If not, double check your program and that the motor wires are connected properly.

Feel free to change the settings in the move block in your program and observe how the robot’s behavior changes.

  • increase the number of centimeters
  • change the unit from centimeters to degrees
  • change the direction of the robot

Now add a move right block and try to make the robot turn. Then add a blue motors block and move only one of the motors, C or D (assuming you wired your motors following that convention).

You should now have a few ways to turn the robot.

Alternate Program Run method

Your program will download to slot 0 on the brick by default. You can select a different slot by clicking the number at the bottom of the programming canvas This allows you to load multiple programs on the brick, and to run them using the brick buttons when you want.

You’ll use this method at the competition as you’ll already have downloaded your program to the robot via the download or download and run buttons. You can then run the program on the brick without needing SPIKE App. Practice this periodically during class before we go to the final competition. This also allows you to have multiple versions of a program that vary slightly since you can’t make changes to the program at the judging arena.
