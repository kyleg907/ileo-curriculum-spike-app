Lesson 5: Smarter Programming with data

Up to this point, the blocks we placed have been self-contained. The values we set in the block’s control panel controlled everything about how the block behaves. What if we instead want to change the block’s behavior as the program runs? Variables let us do this.

Sensor Debugging

We’ve used sensor expression blocks with wait until blocks before, but other blocks like conditional and display blocks can also use them as input. We’ve also displayed sensor values using the Dashboard and Dashboard Overview, but this requires that you connect the SPIKE Intelligent brick to the SPIKE App. With the techniques here, you’ll be able to see the sensor data on the SPIKE Intelligent brick display which might be more convenient to debug certain problems.

Programming Exercise 1

Let’s create a program that will display the values from the Distance sensor on the SPIKE brick’s display. This can be useful later when you are working on programs. Admittedly, the SPIKE display is less capable than other MINDSTORMS robots, but we can still print text and numbers to be useful in a pinch.

  1. Add a repeat forever to your program.
  2. Add a light matrix write .
  3. In the light matrix write block, add a ultrasonic sensor distance expression . Now the display will show the distance reading from the sensor.
  4. Add a wait for seconds . This will make it easier for you to read the value on the screen and limit the flashing on the screen (though you might not notice until you write additional data to the display).

Programming Exercise 2

Create a program to make the robot slow down more and more as it gets closer to a wall.

To solve this, we will need a movement block to control our motors, and a Distance (Ultrasonic) sensor to find our distance to an obstacle/wall. The movement block will use the distance sensor’s value to change its power, slowing it down as the distance to the obstacle/wall gets smaller.

  1. Setup the program for movement as you normally would.

  2. The main body of this program is a loop with a set movement speed to and a start moving . You must place the start-moving block here so it uses the speed adjustments.

    • Remember that the pink movement blocks control two motors at once, so this set movement speed block affects both drive motors of your robot.

  3. Test your program. Find an open space on the floor and aim your robot toward a wall that’s at least a few feet away. Be ready to catch and stop the robot if it misbehaves! Your program should look like this.

If there were no obstacles in front of your robot, it will probably speed away at close to full power. The Distance sensor detects a maximum distance of 100 inches (or 255 centimeters). We are feeding that number directly into the power setting on the move block, setting it to 100% power. Each loop, it will re-read the distance and update the movement speed.

Note❓ Questions

  1. How close does your robot get to the wall before stopping (if it stops)? Why?

  2. What is the behavior when the sensor is covered up completely by the wall?

  3. How is the behavior different if you change the distance unit to centimeters?

  4. How small of a power level can you send to the move block before the robot stops? Add or change the Math blocks in the above program so that your robot sends that power level when 12 inches from the wall.
